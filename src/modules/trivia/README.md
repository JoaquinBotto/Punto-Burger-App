# Módulo: Trivia

Responsabilidad de dominio: Motor de trivia, selección y congelamiento de la secuencia de 10 preguntas (3 iniciales, 4 medias, 3 avanzadas), temporizadores autoritativos server-side (`expires_at`), validación de respuestas y cálculo de puntuación oficial (PPA-004, PPA-012, PPA-013).
